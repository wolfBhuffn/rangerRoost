# RANGER_ROOST
> Powerful, minimal operations logging for solo operators.

---

### Overview

**RANGER_ROOST** is an ultra-lightweight, high-performance operational cockpit designed for solo creators, developers, and freelancers. It combines shift logging, real-time rate metrics, agent monitoring, and CLI terminal capabilities into a single, cohesive cyberpunk-inspired dashboard.

Currently in **active development**, RANGER_ROOST focuses on speed, clarity, and precision control over your work sessions and earnings.

---

## ⚡️ Key Features

### ⏱️ Shift Controller
* **Live Session Tracking:** Dynamic real-time timer with live earnings calculations.
* **Variable Rates:** Adjust your hourly rate on-the-fly per operational shift.
* **Session Annotations:** Log detailed shift metadata, goals, and working notes.

### 📊 Tactical Analytics
* **Weekly vs. Lifetime Metrics:** Instant visibility into hours logged and gross earnings.
* **Glassmorphic Interface:** Clean, dark-mode focused UI engineered with Tailwind CSS and `Space Grotesk` typography.
* **Responsive Architecture:** Built for desktop workstations with an integrated mobile command drawer.

### 🖥️ Integrated CLI & Console *(In Progress)*
* Command-line workflow for power users (`log`, `shifts`, `networth`, `status`).
* Instant terminal-based shift triggering and local data persistence.

## 🚀 Quick Start

Since RANGER_ROOST is built as a single-file, zero-build web project, you can run it directly in any browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/wolfsabyters/ranger-roost.git
   cd ranger-roost
   ```

2. **Launch the application:**
   Open `dashboard.html` directly in your browser, or spin up a local development server:
   ```bash
   npx serve .
   ```
